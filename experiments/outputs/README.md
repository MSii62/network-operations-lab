# Experiment outputs

Place your real terminal captures and screenshots in this directory after running the experiments.

The repository intentionally does not fabricate live router output. Expected behavior is documented in each experiment file. Use names such as:

- `01-ospf-failover.txt`
- `02-firewall-and-nat.txt`
- `03-multicast-pim-igmp.txt`
- `04-monitoring-stack.txt`
- `05-automation-and-audit.txt`

This makes the difference clear between configuration prepared in the lab and evidence actually observed during execution.
